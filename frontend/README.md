# Frontend

HTML, CSS и JavaScript. Сервер разработки и сборка — Vite.

```sh
npm ci
npm run dev
```

Откройте адрес, указанный в терминале.

- `index.html` — разметка.
- `style.css` — стили.
- `main.js` — JavaScript.
- `npm run build` — сборка в `dist`.
- `npm run preview` — просмотр готовой сборки.
- `npm run format` — форматирование кода.
